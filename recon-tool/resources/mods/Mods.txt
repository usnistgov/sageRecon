# LOCAL CORRECTIONS -- deliberate, recorded manual curation. 2026-08-26.
# This file is a dated snapshot of MetaMorpheus's mod list. Two entries were
# corrected against Unimod itself. Every load-bearing field (TG, PP, CF) was
# already right in both, so no mass or acceptor changed. Only names and one
# cross-reference changed.
#   1. "Glu to PyroGlu" TG=Q DR=28  ->  "Gln->pyro-Glu".
#      Unimod 28 is titled "Gln->pyro-Glu", mono_mass -17.026549, site Q at
#      Any N-term. The entry said Glu; its own TG and DR said Gln.
#   2. "Water Loss" TG=E PP=Peptide N-terminal DR=23  ->
#      "Water Loss (Glu->pyro-Glu)", DR corrected to Unimod 27. The name keeps
#      the observation AND the likely mechanism: the enrichment test proves the
#      peptide starts with E, not that the water left from that E, so an
#      unhedged mechanism name would overclaim. Unimod 23 ("Dehydrated", -18.010565) does
#      NOT list E as an acceptor at all -- its sites are D/Y/T/S anywhere and
#      N/Q at protein C-term. Unimod 27 ("Glu->pyro-Glu", -18.010565) is site
#      E at Any N-term, matching this entry's mass, residue and position
#      exactly. The separate "Water loss" TG=D entry is correct and untouched.
#   3. Five entries used the ambiguous bare "PP   N-terminal.", which does not
#      say protein or peptide. Resolved by mechanism, not by Unimod's encoding:
#      an enzyme-placed (biological) modification is PROTEIN N-terminal; a
#      spontaneous intramolecular change goes on whatever N-terminus is exposed,
#      so it is PEPTIDE N-terminal.
#        Acetylation TG=X    -> Protein N-terminal.   (enzymatic, NAT)
#        Methylation TG=X    -> Protein N-terminal.   (enzymatic)
#        Succinylation TG=X  -> Protein N-terminal.   (enzymatic)
#        Myristoylation TG=G -> Protein N-terminal.   (enzymatic, co-translational)
#        Gln->pyro-Glu TG=Q  -> Peptide N-terminal.   (abiotic cyclization)
#      NOTE Unimod encodes Myristoyl as G / "Any N-term" / Post-translational,
#      which disagrees with the enzymatic reading used here. The curated list
#      wins by project policy; the disagreement is recorded, not silently
#      resolved. Behaviour is unchanged today -- is_terminal() matches any of
#      these strings -- so no recommendation moves. This edit exists so the
#      protein-N-term work has a vocabulary to build on.
#      STILL AMBIGUOUS, not decided: "Methylation" TG=X PP="C-terminal.".
#   4. ADDED entry "Met-loss+Acetylation" -- not a correction, a local addition.
#      A search that cannot build Met-clipped peptides still shows the Met-excised
#      population, displaced by -131.04 onto the delta-mass axis. Measured on bcell:
#      peak -89.0289, 209 PSMs, 1.0 mDa from Unimod 766 (-89.02992).
#      ⚠ SUPERSEDED BY ITEM 5 BELOW (2026-08-27): this paragraph once read
#      "TG=M states the ONE hard requirement". It no longer does, and the
#      entries no longer say TG=M. The requirement that protein residue 1 IS a
#      Met is now carried by PP and enforced in code, which frees TG to name the
#      EXPOSED residue. Unimod 766 does record site=M -- that is Unimod's
#      encoding of the same fact, not a disagreement.
#      PP="Protein N-terminal, Met loss." is what
#      carries the real acceptor test -- the peptide must sit at protein position
#      0 -- which is rare (0.4-1.6% of PSMs) and therefore discriminating on its
#      own.
#      NO ENZYMOLOGY IS ENCODED HERE, deliberately. Whether residue 2 makes Met
#      excision or acetylation plausible is the READER's call: every
#      aminopeptidase and N-acetyltransferase has its own pattern, and the tool
#      flags the possibility rather than ruling on it.
#      PAIRED FOR ALL FOUR protein-N-term mods in this file, one Met-loss entry
#      each. Masses are the base CF minus the Met residue (C5 H9 N1 O1 S1,
#      131.04048), computed with Unimod's own element masses:
#        Met-loss+Acetylation     C-3 H-7 N-1 S-1       -89.02992   (Unimod 766)
#        Met-loss+Methylation     C-4 H-7 N-1 O-1 S-1  -117.02483
#        Met-loss+Succinylation   C-1 H-5 N-1 O2 S-1    -31.02444
#        Met-loss+Myristoylation  C9 H17 N-1 S-1        +79.15788
#      Only the acetyl form has a Unimod record, so only it carries a DR.
#      ONLY the acetyl form is observed in the three test files (bcell, 209 PSMs).
#      The other three fire on nothing here and are added for chemical
#      completeness, not on evidence from this data set.
#   5. TG ON THE Met-loss ENTRIES NAMES THE EXPOSED RESIDUE. 2026-08-27.
#      Corrected from TG=M on all four. Rationale: the Met that is lost IS
#      protein residue 1, and PP's own words already require it -- a Met that is
#      not there cannot be lost -- so the tool enforces residue 1 = M from PP.
#      That frees TG to mean what it means everywhere else in this file: where
#      the named modification goes. For a Met-loss entry that is the residue the
#      removal EXPOSES, protein residue 2.
#        Met-loss                 TG X    nothing follows the removal
#        Met-loss+Acetylation     TG X    Unimod 1  Acetyl   @ Protein N-term = site N-term
#        Met-loss+Methylation     TG X    Unimod 34 Methyl   @ Protein N-term = site N-term
#        Met-loss+Succinylation   TG X    Unimod 64 Succinyl @ Protein N-term = site N-term
#        Met-loss+Myristoylation  TG G    Unimod 45 and 135 Myristoyl N-term = site G
#      Every TG here is read off the PINNED unimod.xml, not from recollection.
#      THIS IS NOT the withdrawn "TG is the NME rule" design. That one put the
#      NME-permissive SET (A/C/G/S/T/V) on Met-loss+Acetylation, encoding
#      aminopeptidase enzymology as an acceptor list. Acetylation here carries
#      TG=X -- no residue claim at all, the opposite of that. The one residue
#      constraint is myristoylation's Gly, which is that modification's own
#      chemistry as Unimod records it. NOTE the tool still makes NO judgement
#      about whether NME is plausible on a given residue 2; that stays the
#      reader's call.
#   6. ADDED entry "Met-loss" -- Unimod 765, -131.040485, the initiator Met
#      removed with NO following modification. 2026-08-27. It was missing while
#      all four "+mod" forms were present, which is a gap: bare Met excision is
#      a documented co-translational event in its own right. Unimod 765 records
#      site=M, position=Protein N-term, class=Co-translational.
#      It fires on NOTHING in the three test files -- there is no -131.04 peak
#      on any of them, which is unexplained and recorded in NOTES rather than
#      guessed at. Added for completeness and because Unimod documents it.
