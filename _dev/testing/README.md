# Testing Directory

Test data, Sage configs, helper scripts, and recon-tool outputs. Organized so a
cold-start agent can see what's here without re-deriving it. Current project
state lives in `PLAN.md`'s status block; this file is a manifest of the
`testing/` tree only.

## Layout

```text
testing/
├── inputs/          # Raw data — mzML, FASTA, example Sage outputs (all GITIGNORED, local only)
├── configs/         # Sage parameter files (JSON) — TRACKED
├── scripts/         # Helper scripts (Python + PowerShell) — TRACKED
├── reference-data/  # Unimod DB + contaminant tables — TRACKED
├── search-output/   # Sage run output dirs (regenerated each run) — GITIGNORED
├── recon-output/    # recon-tool report/discover output — TRACKED (current only)

└── README.md        # this file
```

**Tracked vs. gitignored, and why:**
- `inputs/` and `search-output/` are **gitignored** — raw data and regenerable
  Sage output are large and reproducible. They live on disk, not in the repo.
- `configs/`, `scripts/`, `reference-data/` are **tracked** — small, hand-authored,
  and needed to reproduce a run.
- `recon-output/` is **tracked** — kept as the current recon-tool result snapshot
  (useful as a diff baseline). Only the current version is kept; superseded
  versions are deleted rather than accumulated.

## Test run results summary

**Open search (primary):** `open-search-params.json` on `B.naive_01steady-state`,
Sage 0.14.6, 172 s, 81,966 PSMs at q<0.01. Key columns: `expmass`, `calcmass`,
`isotope_error`, `hyperscore`, `matched_intensity_pct`, `longest_b`, `longest_y`,
`ms2_intensity`.

**Narrow search (isotope validation):** `narrow-search-params.json`, ~40 s,
59,369 PSMs. Validates the isotope-error correction formula.

**Semi-enzymatic (Phase 6B experiment):** `semi-enzymatic-search-params.json`,
1,226 s (7× slower than open), 44,187 PSMs, 6.4% semi-tryptic. Too slow for
default recon — opt-in only; superseded by the two-pass workflow.

**Serum two-pass digestion (2026-07-15):** two-pass workflow on
`2019-4-9_909c_0311` (human serum). Pass 1 (`serum-digestion-pass1.json`) 18 s →
460 identified proteins; Pass 2 (`serum-digestion-pass2.json`) 8 s → 13,197
confident PSMs. **31.8% semi-tryptic** (20.5% N-ragged, 11.3% C-ragged, N:C
1.8:1), MC 88.3% / 11.7%. Compare to B.naive's 6.2% — the ~5× higher
semi-tryptic rate is the serum peptidome (endogenous proteolysis), the expected
biofluid signal. The script reports this raw breakdown only — the former
composite "digestion score" was removed (2026-07-15, commit 58b3b1f) because it
penalized semi-tryptic as bad digestion, misreading serum biology. Whether a
semi-tryptic rate is expected is a sample-type call for the user. See NOTES
"Known permanent limitations."
