Missed cleavage is the headline, and the weakest link

method spread 3.74 pp
sample spread 15.9 pp

Four independent tools span 15.90 → 19.64 %. Against the between-sample spread recorded in NOTES "ACCEPTANCE CRITERION", the biological signal is 4.3× the method disagreement. Criterion met — but this is the worst ratio in the report.

Ragged termini cannot be compared across enzyme conventions

The two fully-tryptic searches report ragged-N of 1.64 % and 0.54 %. A fully tryptic search cannot generate a ragged peptide, so those are a control near zero, not a measurement — comparing them to Preview's 8.60 % is the exact trap NOTES warns about. Only recon (semi) and Preview are comparable: 6.75 % vs 8.60 %, a 1.85 pp gap against a 24.7 pp between-sample range — 13×. Comfortable.

Fifth independent confirmation

N >> C holds on all four sources. N:C ratios of 2.24, 3.18, 1.21 and 6.62 — every one above 1. Davis Table 3's ragged N/C headers are transposed relative to the tool that produced them. The direction reproduces across tools; the magnitude (1.21 → 6.62) does not.

Why the controls aren't exactly zero

Residual fully-tryptic ragged-N (1.64 % Shepherd, 0.54 % MetaMorpheus) exists because classification uses the first listed protein. A peptide that is tryptic in its true parent can be ragged in the razor protein. recon carries the identical limitation, documented at digestion.rs:390.

The result

All four tools independently put Oxidation first and Carbamidomethyl second among real modifications, and not one of them was told the sample was alkylated. recon reports +57.0207 at rank 3 overall — behind the unmodified population and Oxidation — at 1,291 PSMs, 3.97 %.

Counts are not commensurable

No claim is made on the counts. Mascot's are resolved-ET fractions; Shepherd's run roughly 1.5–2× recon's throughout; NOTES "Prevalence currency" records that these tools report four different quantities. The claim is rank. Mascot also uses PFA=1 against recon's two missed cleavages, and reports by name + site — its site rows are rolled up by mass before comparison, or its C-only row would understate the true +57. It contributes to this section only and must not enter the digestion table.

Settled — MS2 corroborated

recon reports 3.4206 ppm absolute; Preview independently measures 3.5 ppm absolute on the same raw file. Same quantity (median of |error|), same instrument state, 0.08 ppm apart.

Settled — the signed MS2 gap has an external answer

NOTES "MS2 stays ABSOLUTE" records that recon has no signed MS2 number and defers it to Step 5. Preview supplies it: −3.1 ppm, corroborated by its own directional count of 307 fragments high against 9,820 low. A 32:1 imbalance is not compatible with a centred distribution. The true liver MS2 bias is negative and of order −3 ppm, and recon's absolute 3.42 ppm is consistent with it. recon still does not measure the sign — it now has a reference value for the write-up.

Open — do not present as corroborated

recon says the precursor bias is −1.4193 ppm; Preview says 0.0 ppm with a balanced 943/850 split. Both cannot be describing the same population. Candidate explanations, none tested: Preview measured on the .mgf after its own conversion from .raw; the populations differ by an order of magnitude (recon's clean subset 7,519 PSMs vs Preview's ~1,793 precursors); and the two use entirely different peptide sets.

Fifth quantity — keep it out

Preview's off-by-one rate, 6.0 % (119/1973), is an isotope-assignment rate, not a mass error. Do not fold it into a tolerance comparison.

04 What this does not establish

  • Nothing about localization. recon reports an un-localized delta mass plus a population enrichment; the reference tools localize per PSM. Same boundary that retired Gate 5.
  • Nothing outside one instrument class. This is one Orbitrap file. The ion-trap, TOF and Astral tolerance buckets remain unexercised.
  • Not equal populations. Preview kept ProtScore ≥ 20 representative proteins (2,009 peptides); recon Pass 2 searches its own ≥ 2-peptide subset; the FragPipe runs searched the whole database. Direction and scale, not equality.
  • The MetaMorpheus arm is not reproducible from a clean clone. Both producers read Task3-SearchTask/AllPeptides.psmtsv, which is gitignored. Both scripts hard-stop with a named missing input rather than quietly dropping the arm — falsified 2026-09-01 by removing an input and confirming the stop.
  • An earlier version of this report was wrong about Preview. It said there was no Preview mass-accuracy number to compare against. That was true of the UI's inputs but wrong about its output — corrected 2026-09-01, and section 03 is the correction.
  • The archived MSFragger run is not part of this comparison. A closed semi-tryptic liverFragger run (16.16 % missed cleavage) was an intermediate check from a previous session, archived 2026-09-01. Do not cite it and do not re-add it.
