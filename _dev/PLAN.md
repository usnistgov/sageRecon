# Sage-Based Proteomics Reconnaissance Tool — Roadmap

Repo: **github.com/neely/sageRecon**

**Purpose:** A fast, free, alkylation-agnostic reconnaissance tool for unfamiliar
mass-spec data — one Sage open search, one report on what mods are present,
where the signal went, and what tolerances are reasonable. Open spiritual
successor to Byonic Preview.
**Non-goals:** Not an LFQ/quant pipeline. Not a general QC suite. Not a
parameter auto-configuration engine (no re-run loops). Not a second
closed/localized search — that's a human decision downstream of this report.
